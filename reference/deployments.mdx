## Token vesting status

The current registry has no `VESTING_FACTORY` or `TOKEN_VESTING_IMPL` entry. Token vesting is documented as a separate contract primitive, but it is not available on chain `46630` in this snapshot.

Do not infer an address from a development branch or transaction history. A public vesting deployment must add both addresses to the canonical registry before operators create or fund grants.

## Production WOOD token

WOOD exists separately on Robinhood Chain mainnet, chain ID `4663`:

`0xF8BC08092C06dB6148114DCf82AF881F1085f92b`

The token has a fixed supply of 1 billion WOOD. The Sherwood fund protocol is not deployed on that mainnet chain in this documentation snapshot.
