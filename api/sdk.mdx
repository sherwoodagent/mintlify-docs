title: "TypeScript SDK"
description: "Typed calldata encoders and onchain reads for Sherwood integrations."
---

`@sherwoodagent/sdk` contains pure encoders, minimal ABIs, and read helpers. It does not manage keys, create a wallet client, broadcast transactions, or store local CLI state.

## Install

```bash
npm install @sherwoodagent/sdk viem
```

`viem` is a peer dependency.

## Define the current chain

```ts
import { CHAIN_IDS } from "@sherwoodagent/sdk";
import { defineChain } from "viem";

export const robinhoodTestnet = defineChain({
  id: CHAIN_IDS.ROBINHOOD_L2,
  name: "Robinhood L2 Testnet",
  nativeCurrency: { name: "Ether", symbol: "ETH", decimals: 18 },
  rpcUrls: {
    default: { http: ["https://rpc.testnet.chain.robinhood.com"] },
  },
  blockExplorers: {
    default: {
      name: "Blockscout",
      url: "https://explorer.testnet.chain.robinhood.com",
    },
  },
  testnet: true,
});
```

<Warning>
  The SDK registry can retain legacy chain constants and address records for compatibility. For the current public fund deployment, use `CHAIN_IDS.ROBINHOOD_L2` only. Do not infer availability from `SUPPORTED_CHAIN_IDS` or `listDeployments()`.
</Warning>

## Read a vault and prepare a deposit

```ts
import {
  CHAIN_IDS,
  encodeDeposit,
  readVaultInfo,
} from "@sherwoodagent/sdk";
import { createPublicClient, http } from "viem";
import { robinhoodTestnet } from "./chain.js";

const client = createPublicClient({
  chain: robinhoodTestnet,
  transport: http(),
});

const vault = "0xVAULT" as `0x${string}`;
const receiver = "0xSIGNER" as `0x${string}`;
const info = await readVaultInfo(client, vault);

const action = encodeDeposit(
  {
    vault,
    receiver,
    asset: info.asset,
    assetSymbol: info.assetSymbol,
    assetDecimals: info.assetDecimals,
    assets: 10_000_000_000_000_000n,
  },
  CHAIN_IDS.ROBINHOOD_L2,
);
```

Without `currentAllowance`, `encodeDeposit` returns a conservative approval followed by the deposit. Read the live allowance and pass it when you want the encoder to omit an unnecessary approval.

## Sign the prepared action

```ts
for (const tx of action.txs) {
  if (tx.chainId !== CHAIN_IDS.ROBINHOOD_L2) {
    throw new Error(`Unexpected chain ${tx.chainId}`);
  }

  const hash = await walletClient.sendTransaction({
    to: tx.to,
    data: tx.data,
    value: BigInt(tx.value),
  });

  await client.waitForTransactionReceipt({ hash });
}
```

Create `walletClient` in your application with a dedicated signer. The SDK never checks your policy for target allowlists, value limits, or human approval.

## Current encoder surface

| Area | Exports |
| --- | --- |
| Vault | `encodeDeposit`, `encodeRedeem`, `encodeRequestRedeem`, `encodeApproveDepositor`, `encodeSetAgentFeeBps` |
| Governance | `encodePropose`, `encodeVote`, `encodeExecute`, `encodeSettle`, `encodeCancel`, `encodeVeto` |
| Recovery | `encodeUnstick`, `encodeEmergencySettle` |
| Strategy | `encodeStrategyDeploy`, `predictStrategyCloneAddress`, `deriveStrategySalt` |
| Guardian | `encodeGuardianStake`, `encodeGuardianUnstake`, `encodeGuardianDelegate`, `encodeDelegationUnstake`, `encodeSetCommission` |
| Fund | `encodeCreateFund`, `encodeRegisterAgent` |
| Parameters | `encodeGovernorParam`, `encodeProtocolFeeBps` |

Some exported encoders target systems that are not deployed on chain `46630`. Check the relevant deployment address for zero before exposing an encoder to users.

## Current read surface

| Helper | Result |
| --- | --- |
| `readVaultInfo(client, vault)` | Asset, total assets, share supply, owner, governor, pause and liquidity state |
| `readGovernorParams(client, chainId, vault)` | Per-fund parameters and fee configuration |
| `readProposal(client, chainId, vault, id)` | One vault-scoped proposal |
| `readActiveFunds(client, chainId)` | Active funds from the factory |
| `readFundResolution(client, chainId, query)` | Resolve a vault or fund label |

## Error handling

Catch `SdkError` and branch on its code:

```ts
import { SdkError } from "@sherwoodagent/sdk";

try {
  // read or encode
} catch (error) {
  if (error instanceof SdkError) {
    console.error(error.code, error.message);
  }
  throw error;
}
```

The codes are `USAGE`, `UNSUPPORTED`, `UNAVAILABLE`, `NOT_FOUND`, and `INTERNAL`.

## Versioning

The SDK is in `0.x`. Pin an exact version for production-like automation, ignore unknown response fields, and review minor releases for breaking type changes.
