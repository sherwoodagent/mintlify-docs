## Availability

```bash
sherwood strategy list
```

On the current deployment, the supported result is `portfolio`. Other template names that may still appear in generic CLI help are not deployed for public use on chain `46630`.

## Build a proposal

```bash
sherwood strategy propose portfolio \
  --vault 0x... \
  --name "Explicit-route basket" \
  --description "Testnet basket with reviewed entry and exit routes" \
  --duration 24h \
  --amount 0.01 \
  --tokens "0x...,0x..." \
  --weights "6000,4000" \
  --swap-routes "v3:3000,v3:3000" \
  --feed-ids "0x...,0x..." \
  --price-decimals "8,8" \
  --max-slippage 300
```

The lists are positional. Token, route, feed, price-decimal, and weight entry `i` must all describe the same basket slot.

<Warning>
  There are no verified default stock routes in the current CLI registry. Do not copy the route values above without checking that those exact pools and exit paths exist. The values demonstrate command shape, not recommended market configuration.
</Warning>

## Inspect before submission

Add `--write-calls` to write the execute and settlement arrays instead of submitting the proposal:

```bash
sherwood strategy propose portfolio \
  --vault 0x... \
  --tokens "0x...,0x..." \
  --weights "6000,4000" \
  --swap-routes "v3:3000,v3:3000" \
  --feed-ids "0x...,0x..." \
  --price-decimals "8,8" \
  --amount 0.01 \
  --duration 24h \
  --write-calls ./portfolio-calls
```

In signer mode, clone deployment or initialization can still create transactions. Read the prompt and output before confirming.

## Read strategy state

```bash
sherwood strategy status <clone-address>
sherwood strategy status <clone-address> --json
```

The JSON form is intended for monitoring agents. It does not replace independent onchain reads for transaction authorization.

## Rebalance

```bash
sherwood strategy rebalance <clone-address>
```

Only the configured proposer can rebalance while the proposal is executed. The simple command sells all positions and buys them again at the stored weights, so it incurs route, liquidity, slippage, and gas costs on both sides.

## Settle

Portfolio settlement is a governance action:

```bash
sherwood proposal settle --vault 0x... --id <proposal-id>
```

It sells remaining basket balances back to the vault asset. A monitoring system should not mark the strategy complete until the proposal state is `Settled`.
