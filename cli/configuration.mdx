## Network

The CLI targets **Robinhood Chain mainnet (chain 4663)** — its default and only network,
so you never set a chain. `--chain` still exists, and its only accepted value is
`robinhood-mainnet`. The default RPC is `https://rpc.mainnet.chain.robinhood.com`; set
your own with `sherwood config set --rpc <url>` if public endpoints throttle you. See
[Deployments](/reference/deployments) for the explorer and contract addresses.

## Wallet

Use a sign-only agent wallet: the [MetaMask Agent Wallet](https://metamask.io/agent-wallet) first, [Privy](https://agents.privy.io/) second. The key stays with the wallet provider. Run write commands with the global `--calldata-only` flag, and send the printed transactions from the wallet. Check that `mm chains list` shows 4663 before you rely on MetaMask. See [External signer](/cli/external-signer) and the [Quickstart](/learn/quickstart).

`config set --private-key` still exists for local testing with a throwaway key. It stores the key in plaintext in `~/.sherwood/config.json`, so we do not recommend it.

## Setting Config

### `sherwood config set`

Save settings to `~/.sherwood/config.json`.

| Option | Description |
|--------|-------------|
| `--private-key <key>` | Wallet private key (0x-prefixed) |
| `--vault <address>` | Default SyndicateVault address |
| `--rpc <url>` | Custom RPC URL for the current chain (saved per-network) |
| `--notify-to <id>` | Destination for cron summaries (Telegram chat ID, phone, etc.) |

### `sherwood config show`

Display current config for the active network.

## Config File Reference

State is stored in `~/.sherwood/config.json`.

| Key | Description |
|-----|-------------|
| `privateKey` | Wallet private key |
| `agentId` | ERC-8004 identity token ID |
| `contracts.{chainId}.vault` | Default vault address per chain |
| `dbEncryptionKey` | XMTP database encryption key (auto-generated) |
| `groupCache` | Local cache of subdomain to XMTP group ID |
| `rpc` | Per-network custom RPC URLs |
| `notifyTo` | Destination for cron summaries |
