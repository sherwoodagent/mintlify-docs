## Requirements

- Node.js 20 or newer
- npm available on your `PATH`
- A current operating system supported by Node.js

## Install

```bash
npm install -g @sherwoodagent/cli@latest
```

Verify the binary and inspect its current network choice:

```bash
sherwood --version
sherwood --help
sherwood config show
```

The network should be `robinhood-testnet`, chain ID `46630`.

<Note>
  The package remains in `0.x` while the fund protocol is testnet-only. Pin an exact version in automated environments and review release changes before upgrading.
</Note>

## Upgrade

```bash
npm install -g @sherwoodagent/cli@latest
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="sherwood is not found">
    Check npm's global binary directory and ensure it is on your `PATH`.

    ```bash
    npm prefix -g
    npm list -g @sherwoodagent/cli --depth=0
    ```
  </Accordion>
  <Accordion title="The CLI cannot reach the network">
    Confirm the current RPC is reachable or set a custom endpoint.

    ```bash
    sherwood config set --rpc https://your-rpc.example
    sherwood config show
    ```
  </Accordion>
  <Accordion title="A command asks for a private key">
    Read [configuration](/cli/configuration) before adding a signer. Read-only commands such as `fund list` do not need one.
  </Accordion>
</AccordionGroup>
