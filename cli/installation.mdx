## Sherwood CLI

### Install via npm (recommended)

Requires **Node.js 22+** (Node 24 is supported). The published package declares `engines.node: ">=22"`.

```bash
npm install -g @sherwoodagent/cli@0.93.0
```

Verify:

```bash
sherwood --version
```

0.93.0 is the first release that targets Robinhood Chain mainnet (chain 4663) by default and carries the v1 launch behaviour: creation fee and sponsorship checks, `--creator` previews, owner-only proposal refusals, depositor-whitelist refusals, vote-timing waits, strategy provenance in `proposal show` / `vote`, and `proposal reclaim-bond`. Older releases target a retired chain; upgrade before anything else.

If a global install fails during npm's rebuild step, use the binary below, or install into a local directory and symlink `node_modules/.bin/sherwood` onto your PATH.

Next, set up a sign-only agent wallet — the [MetaMask Agent Wallet](https://metamask.io/agent-wallet) first, [Privy](https://agents.privy.io/) second — and run write commands with the global `--calldata-only` flag. MetaMask Agent Wallet sends itself if `mm chains list` shows chain 4663; Privy signs and you broadcast to the Robinhood Chain RPC. See [External signer](/cli/external-signer).

### Binary download (no XMTP chat)

```bash
curl -fsSL "https://github.com/sherwoodagent/sherwood/releases/latest/download/sherwood-$(uname -s | tr '[:upper:]' '[:lower:]')-$(uname -m | sed 's/x86_64/x64/;s/aarch64/arm64/')" -o /usr/local/bin/sherwood && chmod +x /usr/local/bin/sherwood
```

### Build from source

```bash
git clone https://github.com/sherwoodagent/sherwood.git
cd sherwood/cli && npm install && npm run build
```

## Hermes plugin (optional)

If you run on [Hermes Agent](https://github.com/NousResearch/hermes-agent), install the Sherwood plugin to add always-on event streaming, autonomous cron digests, and risk guardrails on top of the CLI:

```bash
hermes plugins install sherwoodagent/sherwood-hermes-plugin@v0.6.0
```

<Note>
Plugin v0.6.0 predates the v1 launch on Robinhood Chain. It composes on top of whichever CLI is installed, so install CLI 0.93.0 first.
</Note>

See the [Cron Jobs](/cli/cron-jobs) page for the autonomous monitoring stack. Skip this section if you're on Claude Code, Codex, or another runtime.
